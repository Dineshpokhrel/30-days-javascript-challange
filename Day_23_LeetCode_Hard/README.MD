# Day 23: LeetCode Hard

## Tasks/Activities

### Activity 1: Median of Two Sorted Arrays
- **Task:** Solve the "Median of Two Sorted Arrays" problem on LeetCode.
- **Function:** Implement a function that takes two sorted arrays of integers and returns their median.
- **Log:** Output the median for various test cases, including edge cases.

### Activity 2: Merge k Sorted Lists
- **Task:** Solve the "Merge k Sorted Lists" problem on LeetCode.
- **Function:** Create a function that merges an array of `k` sorted linked lists into one sorted list.
- **Log:** Display the merged list for different test cases.

### Activity 3: Trapping Rain Water
- **Task:** Solve the "Trapping Rain Water" problem on LeetCode.
- **Function:** Write a function that calculates the amount of water trapped after rain using an elevation map.
- **Log:** Show the amount of water trapped for a variety of test cases.

### Activity 4: N-Queens
- **Task:** Solve the "N-Queens" problem on LeetCode.
- **Function:** Develop a function that places `n` queens on an `n x n` chessboard such that no two queens threaten each other, and return all distinct solutions.
- **Log:** Output distinct solutions for several test cases.

### Activity 5: Word Ladder
- **Task:** Solve the "Word Ladder" problem on LeetCode.
- **Function:** Implement a function that finds the length of the shortest transformation sequence from a begin word to an end word using a given dictionary.
- **Log:** Output the length of the shortest transformation sequence for different test cases.

## Feature Requests

1. **Median of Two Sorted Arrays Script:** Create a script with a function to solve the "Median of Two Sorted Arrays" problem and log the results.
2. **Merge k Sorted Lists Script:** Develop a script to merge `k` sorted linked lists and log the merged list.
3. **Trapping Rain Water Script:** Implement a script to calculate trapped rainwater and log the outcome.
4. **N-Queens Script:** Write a script to solve the N-Queens problem and log distinct solutions.
5. **Word Ladder Script:** Create a script to find and log the shortest transformation sequence in a word ladder.
